# Audit Trail, Pending Registrations, Account Emails and Application Credentials Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Heimdall UI four administrator capabilities the API already offers, as four use cases on four branches:
- UI-34, the audit trail (#136);
- UI-35, a scope's pending registrations (#137);
- UI-36, account emails to a person (#138);
- UI-37, an application's credentials (#139).

**Architecture:** Each use case follows the app's feature shape: a domain interface returning `Result<T>`, a data class over the generated Retrofit client, and Riverpod `Notifier` controllers with sealed states driving `ConsumerStatefulWidget` screens. Part A first refreshes the vendored OpenAPI snapshot and regenerates `packages/heimdall_api_client`, then adds the shared pieces the later parts use: a `rateLimited` failure kind with a `Retry-After` hint, and a date-time formatter. Each part is a branch of its own, cut from `develop` after the previous one merges.

**Tech Stack:** Flutter 3.47.7 / Dart 3.13 (at `/root/develop/flutter-3.47.7`), flutter_riverpod 3, go_router, dio + retrofit (generated by swagger_parser), mocktail, flutter_test.

**Spec:** `docs/superpowers/specs/2026-10-14-audit-registrations-emails-credentials-design.md`

## Decisions made in this plan

1. **Repositories.** Each of these gets its own interface, provider and API class:
   - the audit trail: `AuditLogRepository` / `auditLogRepositoryProvider` / `ApiAuditLogRepository(AuditClient)`;
   - pending registrations: `PendingRegistrationRepository` / `pendingRegistrationRepositoryProvider` / `ApiPendingRegistrationRepository(ScopeClient)`;
   - application credentials: `ApplicationCredentialRepository` / `applicationCredentialRepositoryProvider` / `ApiApplicationCredentialRepository(ApplicationCredentialClient)`.

   Reasons: `ApiScopeRepository` is already 415 lines, and credentials come from a separate generated client. The spec allowed either.

   Account emails are two methods added to the existing `PersonRepository` (`sendVerificationEmail`, `sendPasswordReset`), because `PersonClient` already serves it.
2. **Client method names** after regeneration, checked by running the generator:
   - `AuditClient.auditList({DateTime? from, DateTime? to, String? actorId, String? action, String? targetId, bool? succeeded, int? pageNumber, int? pageSize})` → `AuditLogEntryOutputPaginatedOutput`.
   - `ScopeClient.scopeListPendingRegistrations({required String id, int? pageNumber, int? pageSize})` → `PendingRegistrationOutputPaginatedOutput`.
   - `ScopeClient.scopeDiscardPendingRegistration({required String id, required String registrationId})` → `DiscardPendingRegistrationCommandOutputDataOutput`.
   - `PersonClient.personSendVerificationEmail({required String id})` and `personSendPasswordReset({required String id})`.
   - `ApplicationCredentialClient`:
     - `applicationCredentialIssue({required String scopeId, required String id, IssueApplicationCredentialCommand? body})`;
     - `applicationCredentialList({required String scopeId, required String id})`, whose response's `data.credentials` holds the list;
     - `applicationCredentialRevoke({required String scopeId, required String id, required String credentialId})`.

   If regeneration produces different names, use the generated ones and record that in the report.
3. **Rate limiting.**
   - `FailureKind.rateLimited` is new.
   - `Failure` gains `retryAfter` (a `Duration?`) and a getter `retryHint`: "Try again in N seconds." when `retryAfter` is set, otherwise `null`.
   - `failureFromDioException` maps `429` to `rateLimited` and reads `Retry-After` as whole seconds.
   - `displayMessage`, when there are no `errors`, says "Too many requests." followed by the hint, or "Try again later." without one.
   - `ErrorBanner` appends `retryHint` as an extra line when it is non-null.

   So a handler's `429`, which has no header, shows the API's message alone. A limiter `429` shows the message plus "Try again in N seconds."
4. **Date and time.** `formatDateTime(BuildContext context, DateTime at)` lives in `lib/shared/formatting/date_time_format.dart`. It returns `'${formatMediumDate(local)} ${formatTimeOfDay(TimeOfDay.fromDateTime(local), alwaysUse24HourFormat: MediaQuery.alwaysUse24HourFormatOf(context))}'`.
5. **Audit date bounds.** `auditBoundsFor(DateTime firstDay, DateTime lastDay)` lives in the domain, and takes the picked days rather than Flutter's `DateTimeRange` so the domain imports no Flutter. It returns `(from: DateTime, to: DateTime)`:
   - `from` is the local start of `firstDay`'s day, converted with `.toUtc()`;
   - `to` is the local `23:59:59.999` of `lastDay`'s day, converted with `.toUtc()`.
6. **Identifier input.**
   - The audit actor and target filters trim, lowercase and validate against the UUID pattern `^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$` (case-insensitive).
   - Do not import `outstanding_erasure.dart`. Copy the expression into `lib/shared/formatting/identifier.dart` as `bool isIdentifier(String value)` and `String normaliseIdentifier(String value)`.
   - Do not refactor UI-32's private copy (`_uuid` in `outstanding_erasure.dart`) in this plan. Its owner can switch to the shared function later.
7. **Credential expiry.** `credentialExpiryFor(DateTime pickedDay)` returns the local `23:59:59.999` of that day as UTC. The date picker's `firstDate` is today and its `lastDate` is today plus 5 years.
8. **Routes and navigation.**
   - `/audit-log` gets a `roleMayReach` arm (`role == Role.systemAdmin`) and a `destinationsFor` entry after **Erasure requests**: `label: 'Audit log'`, `icon: Icons.history_outlined`, `selectedIcon: Icons.history`.
   - `/scopes/:scopeId/pending-registrations` is a new `GoRoute`. `roleMayReach` already covers it, since `/scopes/` is open to non-User roles.
9. **Who sees what.**
   - UI-35's link shows when the caller is a System Admin, or when `principal.ownedScopeIds` contains the scope id.
   - UI-36's card shows when the caller is a System Admin, or a Scope Admin viewing a person whose role is `Role.user`.
   - UI-37's card shows on any application the screen opened, except a deleted one (`state.isReadOnly`). The API is the authority, and a `403` is shown like any refusal.
10. **Message texts** are the spec's, verbatim: §4–§7 for screen copy, the AF lists for notices.

These are the five inputs or failures the spec implies but does not test that are most likely to bite someone, most likely first. Each line's test is in the named task.

1. **A date range picked west of UTC.** An admin in UTC−3 picks 14 Oct. An entry recorded at 15 Oct 01:30 UTC (14 Oct 22:30 local) must be included, and one at 14 Oct 02:00 UTC (13 Oct local) excluded. Test: `GivenADayPickedWestOfUtc_WhenBounded_ThenTheBoundsCoverTheLocalDay` (Task A3).
2. **An identifier pasted with spaces or capitals** into the actor or target filter must be accepted and sent normalised, not refused. Test: `GivenAnIdentifierWithSpacesAndCapitals_WhenFiltered_ThenItIsSentNormalised` (Task A4).

4. **Issuing while another admin has just issued the second credential** (the button was enabled when the list loaded) must show the API's `409` message and reload the list. Test: `GivenTheLimitWasReachedMeanwhile_WhenIssuing_ThenTheMessageShowsAndTheListReloads` (Task D2).
5. **A cooldown `429` without `Retry-After`** must show only the API's message, with no "Try again later." appended. A limiter `429` with the header must add "Try again in N seconds." Tests: `GivenA429WithoutRetryAfter_WhenShown_ThenOnlyTheApiMessageAppears` and `GivenA429WithRetryAfter_WhenMapped_ThenTheHintNamesTheSeconds` (Task A2).

  test('GivenA429WithRetryAfter_WhenMapped_ThenTheHintNamesTheSeconds', () {
    // Given
    final error = DioException(
      requestOptions: RequestOptions(path: '/api/auth/login'),
      response: Response<dynamic>(
        requestOptions: RequestOptions(path: '/api/auth/login'),
        statusCode: 429,
        headers: Headers.fromMap(<String, List<String>>{
          'retry-after': <String>['37'],
        }),
        data: <String, dynamic>{
          'errors': <String>['Too many requests. Try again later.'],
        },
      ),
      type: DioExceptionType.badResponse,
    );

    // When
    final failure = failureFromDioException(error);

    // Then
    expect(failure.kind, FailureKind.rateLimited);
    expect(failure.retryAfter, const Duration(seconds: 37));
    expect(failure.retryHint, 'Try again in 37 seconds.');
    expect(failure.errors, <String>['Too many requests. Try again later.']);
  });

  test('GivenA429WithoutRetryAfter_WhenMapped_ThenThereIsNoHint', () {
    // Given — a handler's 429, such as an account email's cooldown
    final error = DioException(
      requestOptions: RequestOptions(path: '/api/persons/x/password-reset'),
      response: Response<dynamic>(
        requestOptions: RequestOptions(path: '/api/persons/x/password-reset'),
        statusCode: 429,
        data: <String, dynamic>{
          'errors': <String>[
            'An email of this kind was sent to this person recently. Try again in a few minutes.',
          ],
        },
      ),
      type: DioExceptionType.badResponse,
    );

    // When
    final failure = failureFromDioException(error);

    // Then
    expect(failure.kind, FailureKind.rateLimited);
    expect(failure.retryAfter, isNull);
    expect(failure.retryHint, isNull);
  });

  test('GivenAnUnreadableRetryAfter_WhenMapped_ThenItIsIgnored', () {
    // Given — an HTTP-date, or garbage, rather than whole seconds

      ),
      type: DioExceptionType.badResponse,
    );

    // When

    // Then

    this.actorId,
    this.actorRole,

class AuditLogFilter {

    this.lastDay,

  final String? action;

  final bool? succeeded;

      firstDay != null ||
      lastDay != null ||
      action != null ||
      actorId != null ||
      targetId != null ||
      succeeded != null;

  AuditLogFilter copyWith({
    DateTime? Function()? firstDay,
    DateTime? Function()? lastDay,
    String? Function()? action,
    String? Function()? actorId,
    String? Function()? targetId,

    lastDay: lastDay == null ? this.lastDay : lastDay(),
    action: action == null ? this.action : action(),

import '../../../core/network/envelope.dart';
import '../../../core/result/result.dart';

import '../domain/audit_entry.dart';
import '../domain/audit_log_repository.dart';

/// [AuditLogRepository] over the generated client.
class ApiAuditLogRepository implements AuditLogRepository {
  const ApiAuditLogRepository(this._client);

  final AuditClient _client;

  @override
  Future<Result<Page<AuditEntry>>> list({
    AuditLogFilter filter = const AuditLogFilter(),
    int pageNumber = 1,
    int pageSize = 20,
  }) async {
    final bounds = switch ((filter.firstDay, filter.lastDay)) {
      (final DateTime first, final DateTime last) => auditBoundsFor(first, last),
      _ => null,
    };

    try {
      final response = await _client.auditList(
        from: bounds?.from,
        to: bounds?.to,
        actorId: filter.actorId,
        action: filter.action,
        targetId: filter.targetId,
        succeeded: filter.succeeded,
        pageNumber: pageNumber,
        pageSize: pageSize,
      );

      if (response.success != true) {
        return FailureResult<Page<AuditEntry>>(
          Failure(
            kind: FailureKind.validation,
            errors: response.errors ?? const <String>[],
          ),
        );
      }

      final items = (response.data ?? const <AuditLogEntryOutput>[])
          .map(_fromOutput)
          .toList(growable: false);

      return Success<Page<AuditEntry>>(
        Page<AuditEntry>(
          items: items,
          pageNumber: response.pageNumber ?? pageNumber,
          pageSize: response.pageSize ?? pageSize,
          totalItems: response.totalItems ?? items.length,
          totalPages: response.totalPages ?? 1,
        ),
      );
    } on DioException catch (error) {
      return FailureResult<Page<AuditEntry>>(failureFromDioException(error));
    }
  }
}

AuditEntry _fromOutput(AuditLogEntryOutput o) => AuditEntry(
  id: o.id ?? '',
  recordedAt: o.recordedAt,
  actorId: o.actorId,
  actorRole: o.actorRole == null ? null : roleFromValue(o.actorRole!),
  action: o.action ?? '',
  targetId: o.targetId,
  succeeded: o.succeeded ?? false,
  failureReason: (o.failureReason?.trim().isEmpty ?? true) ? null : o.failureReason,
);

  final int pageNumber;

  AuditLogQuery copyWith({AuditLogFilter? filter, int? pageNumber}) =>

  const AuditLogLoading(super.query);

/// AF-34b, AF-34c, AF-34e — the request failed, and the query that failed is kept.
final class AuditLogFailed extends AuditLogState {
  const AuditLogFailed(super.query, this.failure);

  final Failure failure;
}

final NotifierProvider<AuditLogController, AuditLogState> auditLogControllerProvider =
    NotifierProvider<AuditLogController, AuditLogState>(AuditLogController.new);

/// Owns the audit-trail listing (UI-34).
class AuditLogController extends Notifier<AuditLogState> {
  bool _inFlight = false;
  AuditLogQuery? _queued;

  @override
  AuditLogState build() => const AuditLogLoading(AuditLogQuery());

  Future<void> load() => _fetch(state.query);

  Future<void> goToPage(int pageNumber) => _fetch(state.query.copyWith(pageNumber: pageNumber));

  Future<void> setDays(DateTime firstDay, DateTime lastDay) =>
      _filter(state.query.filter.copyWith(firstDay: () => firstDay, lastDay: () => lastDay));

  Future<void> clearDays() =>
      _filter(state.query.filter.copyWith(firstDay: () => null, lastDay: () => null));

  /// An empty action is no filter at all, as the API reads it.
  Future<void> setAction(String action) {
    final trimmed = action.trim();

    return _filter(state.query.filter.copyWith(action: () => trimmed.isEmpty ? null : trimmed));
  }

  /// AF-34d — `false`, and nothing sent, when [text] is not an identifier.
  bool setActor(String text) => _setIdentifier(
    text,
    (value) => state.query.filter.copyWith(actorId: () => value),
  );

  /// AF-34d, for the target.
  bool setTarget(String text) => _setIdentifier(
    text,
    (value) => state.query.filter.copyWith(targetId: () => value),
  );

  Future<void> setOutcome(bool? succeeded) =>
      _filter(state.query.filter.copyWith(succeeded: () => succeeded));

  Future<void> clearFilters() => _filter(const AuditLogFilter());

  bool _setIdentifier(String text, AuditLogFilter Function(String? value) apply) {
    if (text.trim().isEmpty) {
      _filter(apply(null));

      return true;
    }

    if (!isIdentifier(text)) {
      return false;
    }

    _filter(apply(normaliseIdentifier(text)));

    return true;
  }

  /// A new filter starts at the first page.
  Future<void> _filter(AuditLogFilter filter) =>
      _fetch(state.query.copyWith(filter: filter, pageNumber: 1));

  Future<void> _fetch(AuditLogQuery query) async {
    if (_inFlight) {
      _queued = query;

      return;
    }

    final current = state;
    _inFlight = true;

    state = current is AuditLogLoaded
        ? AuditLogLoaded(query, current.page, busy: true)
        : AuditLogLoading(query);

    try {
      final result = await ref
          .read(auditLogRepositoryProvider)
          .list(filter: query.filter, pageNumber: query.pageNumber);

      state = result.fold(
        onSuccess: (page) => AuditLogLoaded(query, page),
        onFailure: (failure) => AuditLogFailed(query, failure),
      );
    } finally {
      _inFlight = false;
    }

    if (_queued case final queued?) {
      _queued = null;
      await _fetch(queued);

      return;
    }

    // A page past the end — the trail can shrink only through retention, but a
    // narrowed filter can — would show "nothing here" with no pager to go back with.
    if (state case AuditLogLoaded(:final page)
        when page.items.isEmpty && query.pageNumber > 1) {
      await _fetch(
        query.copyWith(pageNumber: page.totalPages.clamp(1, query.pageNumber - 1)),
      );
    }
  }
}

import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../../../core/network/envelope.dart';
import '../../../core/result/result.dart';
import '../domain/pending_registration.dart';
import '../domain/pending_registration_repository.dart';

sealed class PendingRegistrationListState {
  const PendingRegistrationListState(this.pageNumber);

  final int pageNumber;
}

final class PendingRegistrationListLoading extends PendingRegistrationListState {
  const PendingRegistrationListLoading(super.pageNumber);
}

final class PendingRegistrationListLoaded extends PendingRegistrationListState {
  const PendingRegistrationListLoaded(
    super.pageNumber,
    this.page, {
    this.busy = false,
    this.notice,
    this.discardFailure,
  });

  final Page<PendingRegistration> page;
  final bool busy;

  /// "Registration discarded." or AF-35d's "That registration no longer exists."
  final String? notice;

  /// AF-35b/AF-35f on a discard — the list itself is kept.
  final Failure? discardFailure;
}

/// AF-35b, AF-35c, AF-35f on the list.
final class PendingRegistrationListFailed extends PendingRegistrationListState {
  const PendingRegistrationListFailed(super.pageNumber, this.failure);

  final Failure failure;
}

final pendingRegistrationListControllerProvider = NotifierProvider.family<
  PendingRegistrationListController,
  PendingRegistrationListState,
  String
>(PendingRegistrationListController.new);

/// Owns a scope's pending-registration listing (UI-35). The family argument is
/// the scope id.
class PendingRegistrationListController extends Notifier<PendingRegistrationListState> {
  PendingRegistrationListController(this.arg);

  final String arg;
  bool _inFlight = false;
  int? _queued;

  PendingRegistrationRepository get _repository =>
      ref.read(pendingRegistrationRepositoryProvider);

  @override
  PendingRegistrationListState build() => const PendingRegistrationListLoading(1);

  Future<void> load() => _fetch(state.pageNumber);

  Future<void> goToPage(int pageNumber) => _fetch(pageNumber);

  Future<void> discard(PendingRegistration registration) async {
    final result = await _repository.discard(arg, registration.id);
    final failure = result.failureOrNull;

    if (failure != null && failure.kind != FailureKind.notFound) {
      if (state case final PendingRegistrationListLoaded loaded) {
        state = PendingRegistrationListLoaded(
          loaded.pageNumber,
          loaded.page,
          discardFailure: failure,
        );
      }

      return;
    }

    await _fetch(state.pageNumber);

    if (state case final PendingRegistrationListLoaded loaded) {
      state = PendingRegistrationListLoaded(
        loaded.pageNumber,
        loaded.page,
        notice: failure == null ? 'Registration discarded.' : 'That registration no longer exists.',
      );
    }
  }

  Future<void> _fetch(int pageNumber) async {
    if (_inFlight) {
      _queued = pageNumber;

      return;
    }

    final current = state;
    _inFlight = true;

    state = current is PendingRegistrationListLoaded
        ? PendingRegistrationListLoaded(pageNumber, current.page, busy: true)
        : PendingRegistrationListLoading(pageNumber);

    try {
      final result = await _repository.list(arg, pageNumber: pageNumber);

      state = result.fold(
        onSuccess: (page) => PendingRegistrationListLoaded(pageNumber, page),
        onFailure: (failure) => PendingRegistrationListFailed(pageNumber, failure),
      );
    } finally {
      _inFlight = false;
    }

    if (_queued case final queued?) {
      _queued = null;
      await _fetch(queued);

      return;
    }

    // Discarding the last row of the last page leaves an empty page past the end.
    if (state case PendingRegistrationListLoaded(:final page)
        when page.items.isEmpty && pageNumber > 1) {
      await _fetch(page.totalPages.clamp(1, pageNumber - 1));
    }
  }
}

enum AccountEmail { verification, passwordReset }

class AccountEmailsState {
  const AccountEmailsState({this.sending, this.sent, this.failure});

  /// The email being sent now; both actions are disabled meanwhile.
  final AccountEmail? sending;

  /// The email last handed to the sender.
  final AccountEmail? sent;

  /// AF-36a…d — the API's refusal of the last attempt.
  final Failure? failure;
}

final accountEmailsControllerProvider =
    NotifierProvider.family<AccountEmailsController, AccountEmailsState, String>(
      AccountEmailsController.new,
    );

/// Sends a person's account emails for an administrator (UI-36).
class AccountEmailsController extends Notifier<AccountEmailsState> {
  AccountEmailsController(this.arg);

  /// The person's id.
  final String arg;

  @override
  AccountEmailsState build() => const AccountEmailsState();

  /// `true` when the email was handed to the sender. A second request while
  /// one is in flight is ignored rather than queued.
  Future<bool> send(AccountEmail kind) async {
    if (state.sending != null) {
      return false;
    }

    state = AccountEmailsState(sending: kind);
    final repository = ref.read(personRepositoryProvider);
    final result = await switch (kind) {
      AccountEmail.verification => repository.sendVerificationEmail(arg),
      AccountEmail.passwordReset => repository.sendPasswordReset(arg),
    };

    state = result.fold(
      onSuccess: (_) => AccountEmailsState(sent: kind),
      onFailure: (failure) => AccountEmailsState(failure: failure),
    );

    return result.isSuccess;
  }
}

/// Whether the API would accept a credential now (UC-54).
enum CredentialStatus { live, revoked, expired }

/// One of an application's credentials, as listed. The secret is never here:
/// it is shown once, when issued, and Heimdall keeps only its hash.
class ApplicationCredential {
  const ApplicationCredential({
    required this.id,
    required this.live,
    this.createdAt,
    this.expiresAt,
    this.revokedAt,
    this.lastUsedAt,
  });

  final String id;
  final DateTime? createdAt;
  final DateTime? expiresAt;
  final DateTime? revokedAt;
  final DateTime? lastUsedAt;

  /// The API's own verdict: not revoked and not expired.
  final bool live;

  CredentialStatus get status => live
      ? CredentialStatus.live
      : revokedAt != null
      ? CredentialStatus.revoked
      : CredentialStatus.expired;
}

/// A credential just issued (UC-53), carrying its secret — which exists in the
/// client only for as long as the one-time dialog shows it.
class IssuedCredential {
  const IssuedCredential({
    required this.id,
    required this.secret,
    this.createdAt,
    this.expiresAt,
  });

  final String id;
  final String secret;
  final DateTime? createdAt;
  final DateTime? expiresAt;
}

/// The expiry for a credential that should last through [pickedDay]: the last
/// millisecond of that local day, as UTC.
DateTime credentialExpiryFor(DateTime pickedDay) =>
    DateTime(pickedDay.year, pickedDay.month, pickedDay.day, 23, 59, 59, 999).toUtc();

import 'package:dio/dio.dart';
import 'package:heimdall_api_client/export.dart';

import '../../../core/network/envelope.dart';
import '../../../core/result/result.dart';
import '../domain/application_credential.dart';
import '../domain/application_credential_repository.dart';

/// [ApplicationCredentialRepository] over the generated client.
class ApiApplicationCredentialRepository implements ApplicationCredentialRepository {
  const ApiApplicationCredentialRepository(this._client);

  final ApplicationCredentialClient _client;

  @override
  Future<Result<List<ApplicationCredential>>> list(String scopeId, String applicationId) async {
    try {
      final response = await _client.applicationCredentialList(scopeId: scopeId, id: applicationId);

      if (response.success != true) {
        return FailureResult<List<ApplicationCredential>>(_refusal(response.errors));
      }

      return Success<List<ApplicationCredential>>(
        (response.data?.credentials ?? const <ApplicationCredentialOutput>[])
            .map(
              (o) => ApplicationCredential(
                id: o.id ?? '',
                live: o.live ?? false,
                createdAt: o.createdAt,
                expiresAt: o.expiresAt,
                revokedAt: o.revokedAt,
                lastUsedAt: o.lastUsedAt,
              ),
            )
            .toList(growable: false),
      );
    } on DioException catch (error) {
      return FailureResult<List<ApplicationCredential>>(failureFromDioException(error));
    }
  }

  @override
  Future<Result<IssuedCredential>> issue(
    String scopeId,
    String applicationId, {
    DateTime? expiresAt,
  }) async {
    try {
      final response = await _client.applicationCredentialIssue(
        scopeId: scopeId,
        id: applicationId,
        body: IssueApplicationCredentialCommand(expiresAt: expiresAt),
      );

      if (response.success != true) {
        return FailureResult<IssuedCredential>(_refusal(response.errors));
      }

      final data = response.data;

      if (data == null || data.secret == null || data.id == null) {
        return const FailureResult<IssuedCredential>(_incompleteResponse);
      }

      return Success<IssuedCredential>(
        IssuedCredential(
          id: data.id!,
          secret: data.secret!,
          createdAt: data.createdAt,
          expiresAt: data.expiresAt,
        ),
      );
    } on DioException catch (error) {
      return FailureResult<IssuedCredential>(failureFromDioException(error));
    }
  }

  @override
  Future<Result<void>> revoke(String scopeId, String applicationId, String credentialId) async {
    try {
      final response = await _client.applicationCredentialRevoke(
        scopeId: scopeId,
        id: applicationId,
        credentialId: credentialId,
      );

      return response.success == true
          ? const Success<void>(null)
          : FailureResult<void>(_refusal(response.errors));
    } on DioException catch (error) {
      return FailureResult<void>(failureFromDioException(error));
    }
  }
}

Failure _refusal(List<String>? errors) =>
    Failure(kind: FailureKind.validation, errors: errors ?? const <String>[]);

const Failure _incompleteResponse = Failure(
  kind: FailureKind.unknown,
  errors: <String>['The API returned an incomplete response.'],
);

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';

import '../../../core/result/result.dart';
import '../domain/application_credential.dart';
import '../domain/application_credential_repository.dart';

typedef CredentialsKey = ({String scopeId, String applicationId});

class CredentialsState {
  const CredentialsState({
    this.credentials,
    this.loadFailure,
    this.busy = false,
    this.actionFailure,
    this.notice,
  });

  /// `null` until the first load answers.
  final List<ApplicationCredential>? credentials;
  final Failure? loadFailure;

  /// An issue or a revoke is in flight.
  final bool busy;

  /// AF-37b…e — the API's refusal of the last issue or revoke.
  final Failure? actionFailure;
  final String? notice;

  int get liveCount =>
      credentials?.where((c) => c.status == CredentialStatus.live).length ?? 0;

  /// At most two may be live (FR-AP-11 in the API); the API decides in the end.
  bool get mayIssue => credentials != null && liveCount < 2 && !busy;

  CredentialsState copyWith({
    List<ApplicationCredential>? credentials,
    Failure? Function()? loadFailure,
    bool? busy,
    Failure? Function()? actionFailure,
    String? Function()? notice,
  }) => CredentialsState(
    credentials: credentials ?? this.credentials,
    loadFailure: loadFailure == null ? this.loadFailure : loadFailure(),
    busy: busy ?? this.busy,
    actionFailure: actionFailure == null ? this.actionFailure : actionFailure(),
    notice: notice == null ? this.notice : notice(),
  );
}

final applicationCredentialsControllerProvider = NotifierProvider.family<
  ApplicationCredentialsController,
  CredentialsState,
  CredentialsKey
>(ApplicationCredentialsController.new);

/// Owns an application's credentials card (UI-37). The secret of a newly
/// issued credential is handed back to the caller and never kept here.
class ApplicationCredentialsController extends Notifier<CredentialsState> {
  ApplicationCredentialsController(this.arg);

  final CredentialsKey arg;

  ApplicationCredentialRepository get _repository =>
      ref.read(applicationCredentialRepositoryProvider);

  @override
  CredentialsState build() => const CredentialsState();

  Future<void> load() async {
    final result = await _repository.list(arg.scopeId, arg.applicationId);

    state = result.fold(
      onSuccess: (credentials) => state.copyWith(credentials: credentials, loadFailure: () => null),
      onFailure: (failure) => state.copyWith(loadFailure: () => failure),
    );
  }

  Future<Result<IssuedCredential>> issue({DateTime? expiresAt}) async {
    state = state.copyWith(busy: true, actionFailure: () => null, notice: () => null);
    final result = await _repository.issue(arg.scopeId, arg.applicationId, expiresAt: expiresAt);

    if (result.failureOrNull case final Failure failure) {
      state = state.copyWith(busy: false, actionFailure: () => failure);
    } else {
      state = state.copyWith(busy: false);
    }

    // Reloaded either way: on success to show the new row; on AF-37b because
    // somebody else's credential is why it was refused; on a transport failure
    // because the request may have landed (AF-37g).
    await load();

    return result;
  }

  Future<void> revoke(ApplicationCredential credential) async {
    state = state.copyWith(busy: true, actionFailure: () => null, notice: () => null);
    final result = await _repository.revoke(arg.scopeId, arg.applicationId, credential.id);

    state = result.fold(
      onSuccess: (_) => state.copyWith(busy: false, notice: () => 'Credential revoked.'),
      onFailure: (failure) => state.copyWith(busy: false, actionFailure: () => failure),
    );

    await load();
  }
}
```
